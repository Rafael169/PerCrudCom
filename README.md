# 👨‍💼 PerCrudCom - Sistema de Gestión de Personas

Proyecto realizado como práctica para reforzar conocimientos en desarrollo de APIs con Spring Boot. Se implementó un CRUD básico, integración con base de datos y funcionalidades adicionales como uso de DTOs, Lombok y Query Methods.

## 📌 Descripción

- 🕒 Tiempo estimado de aprendizaje en el CRUD: **aproximadamente 3 horas**
- 📦 Proyecto enfocado en aprender buenas prácticas en la estructura de una API REST usando Spring Boot
- 🎯 Se integraron herramientas modernas para facilitar el desarrollo y reducir la repetición de código

## 🧰 Tecnologías utilizadas

- Java 17+
- Spring Boot
- Spring Data JPA
- MySQL
- **Lombok** (para generar automáticamente getters, setters y constructores)
- **DTOs (Data Transfer Object)** para transportar datos entre capas
- **Query Methods** en los repositorios para consultas personalizadas

## 🚀 Funcionalidades

- ✅ CRUD completo sobre entidades de persona
- 🔐 Implementación de un **login básico** con uso de `Query Methods`
- 🧠 **Aprendizaje clave:** no conocía el uso de `Query Methods`, por lo que este proyecto fue muy útil para entender su funcionamiento y sigo investigando más sobre ello
